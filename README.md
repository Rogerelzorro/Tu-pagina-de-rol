# Tu pagina de rol
Respositorio sobre el que se contruye la pagina para jugar rol online "Tu pagina de rol". Si quieres colaborar, no detroces lo que ya hay, gracias.

Este proyecto fue iniciado como una forma de jugar el juego de rol "Anima Beyond Fantasy" online con todas las facilidades posibles. Por lo que es el sistema que mas cariño tiene.

Bienvenido a este intento de crear una buena pagina donde jugar rol online, con registros sin correo o anuncions.
Para el usuario medio, tendreis facilidad de crear partidas, personajes y todo lo necesario para poder jugar usando las normas de los diferentes juegos de rol que tenemos preparados.
Y con un poco de conocimientos de programacion, podreis crear con total libertad todo lo necesario para modificar tus propias partidas de rol, poner nuevos sistemas de rol en la pagina...
